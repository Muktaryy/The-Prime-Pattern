# Experiment 23 foundation: an aligned finite random-sieve model

Date: 2026-11-26
Status: Mathematical model specification; no prime-data experiment authorized yet.

## 1. Purpose and scope

Construct a finite stochastic model for prime indicators on integers n in a range [X, X+L), with fixed aligned blocks of length b and initial offset a0=1. The model must reproduce:

1. The Hardy–Littlewood one-point density for integers coprime to b.
2. The finite-cutoff Hardy–Littlewood pair density for two such integers.
3. The exact aligned block-count covariance implied by those pair probabilities.

This is a model definition and derivation, not a theorem about actual primes. It does not assert that actual primes are generated by this random process.

## 2. Notation and eligibility

Let b be even (the initial cases are b=10, 30, 210), and let
[
Q_b = b/phi(b).
]
An integer n is eligible if gcd(n,b)=1. Integers not eligible are assigned model prime indicator Y_n=0.

Choose a prime cutoff z at least as large as the largest prime divisor of b. Define
[
Theta_z = prod_{ple z}(1-1/p).
]
For a fixed range beginning at X, choose z so that
[
Theta_zlog X ge 1.
]
This guarantees the thinning probability below is at most one for every n≥X. The cutoff is fixed for the entire range, not changed from block to block.

## 3. Random-sieve stage

For each prime p≤z, independently:

- If p divides b, set the forbidden residue a_p=0 deterministically.
- If p does not divide b, choose a_p uniformly from {0,1,...,p−1}.

The deterministic choice a_p=0 for p|b is an alignment conditioning: eligible n are already nonzero modulo every p|b, so these primes remove no eligible integers. It is an adaptation of the random-residue model, not the unconditioned BFT random model.

## 8. Local obstructions

For the initial even b values, every eligible n is odd, and every difference d between two eligible integers is even. Every prime p not dividing b is therefore odd. For such p, ν_p(d) is either 1 or 2, both strictly less than p. Thus no local pair factor vanishes.

For other b or other tuple sizes, local admissibility must be checked explicitly. A zero local factor means the corresponding tuple is impossible in the model and in the associated singular series.

## 9. What this model does and does not establish

It establishes, by direct probability calculation:

- Exact marginal probabilities Q_b/log n for eligible n.
- Exact finite-cutoff pair probabilities with the aligned truncated singular series.
- Exact finite-cutoff block means and pairwise block covariances.
- A fully specified stochastic process suitable for simulation.

It does not establish:

- That actual primes are independent thinnings of this random sieve.
- That the full Hardy–Littlewood conjecture is true.
- That matching pair probabilities suffices to match higher-order distributions.
- That the model is the uniquely correct null for empirical prime residuals.
- Any statistical significance, power, or sample-size claim.

The unconditioned Banks–Ford–Tao random-residue model chooses every a_p uniformly. This construction conditions the forbidden residue to be 0 for p|b. That conditioning is deliberate and must remain explicit in any description or citation.

## 10. Required implementation checks before simulation

A later implementation must test:

1. For each b in {10,30,210}, construct R_b independently and verify |R_b|=φ(b).
2. For every eligible n, calculate the exact marginal from the finite product and verify it equals Q_b/log n.
3. For many pairs (n,m), calculate the direct local survival product and compare it with the factored singular-series expression.
4. Verify that pairs with the same d have the same normalized pair factor.
5. Verify empirical simulation frequencies against theoretical marginal and pair probabilities on small toy ranges, with Monte Carlo error bars.
6. Verify block means, variances, and lag covariances against direct summation of the exact indicator formulas.
7. Fix and record z, range, b, a0, random seed, PRNG, and thinning convention before any prime-data comparison.
8. Keep model development ranges separate from any eventual held-out prime range.

No empirical comparison with actual primes is part of this foundation note.
