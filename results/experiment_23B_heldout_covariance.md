# Experiment 23B — held-out aligned block residual covariance

Date: 2026-11-26  
Status: Completed; independent audit found the individual comparisons usable as model-compatibility checks, but the original global maximum p-value is withdrawn because its joint null calibration was not valid.

## 1. Holdout and data validation

The tested half-open interval was [100171, 200341), length 100,170. It begins at 1 modulo 210 and contains exactly:

- 10,017 blocks of length 10.
- 3,339 blocks of length 30.
- 477 blocks of length 210.

The interval contains 8,407 primes. The first is 100,183 and the last is 200,329.

The prime list was initially generated by a sieve. A separate segmented-sieve implementation was subsequently run independently; it also returned 8,407 primes, first 100,183 and last 200,329. The three block-count tables each sum to 8,407.

## 2. Cutoff selected before analysis

The cutoff is the largest prime z satisfying
[
Theta_zlog Xge1,qquad
Theta_z=prod_{ple z}(1-1/p),quad X=100171.
]

The result is:
- z=613.
- Theta_613=0.08693500077318561.
- Theta_613 log X=1.0010247160915315.
- The next prime 617 fails the condition.
- Maximum thinning probability at the left endpoint is 0.9989763328766421.

The same cutoff was used across the complete interval and all blocks.

## 3. Test statistic

For each b in {10,30,210}, the block residual is
[
e_i^{(b)}=P_i^{(b)}-mu_i^{(b)},qquad
mu_i^{(b)}=rac{b}{phi(b)}
sum_{substack{nin B_i^{(b)}\(n,b)=1}}rac1{log n}.
]

For each lag k=1,2,3, the statistic is the average over block pairs of
[
e_i^{(b)}e_{i+k}^{(b)}
-operatorname{Cov}_{model}(C_i^{(b)},C_{i+k}^{(b)}),
]
using the exact finite-cutoff covariance, with the actual logarithms at each integer.

Each b-specific set of statistics was calibrated using 5,000 model simulations. Each replicate draws one forbidden residue per applicable prime (shared over the entire interval) and independent thinning coins. The three b-specific simulations were generated independently; they therefore do not reproduce the joint dependence of the nine observed statistics computed from the same nested prime-count sequence.

## 4. Results

### Global test — withdrawn

The previously reported maximum-statistic p-value of 0.9652 is **not a valid calibrated global p-value**. Independent simulations for b=10,30,210 were combined by replicate index, while the observed statistics share the same prime sequence and nested block partitions. The null simulation did not preserve that joint dependence. Do not cite 0.9652 as inferential evidence.

A dependence-robust Bonferroni adjustment of the nine reported marginal p-values gives 1.0, since the smallest marginal p-value is 0.3307. Thus there is still no rejection at conventional levels, without relying on the invalid joint calibration.

Important diagnostic limitation: the code subtracts the same analytic covariance array from the observed statistic and every simulation, then centers by the simulated mean. The analytic covariance therefore cancels exactly from the reported z-scores and p-values. The individual p-values still compare the observed raw residual cross-product with its simulated distribution, but they do **not** validate the analytic covariance formula. The simulated mean should separately be checked against the exact theoretical expectation of zero.

## 5. Interpretation

On this held-out interval, the observed lag-1 to lag-3 residual covariance statistics for block lengths 10, 30, and 210 are not unusual under the specified aligned finite random-sieve model with z=613.

This is a failure to detect a departure, not proof that:
- the random-sieve model is true;
- actual primes are independent;
- higher-order correlations are captured;
- the full Hardy–Littlewood conjectures hold.

The result applies only to this interval, these three block lengths, these three lags, this cutoff rule, and this particular model. The finite random sieve is an adapted, alignment-conditioned version of the BFT random-residue construction.

No formal power calculation was performed. In particular, do not infer power against a zero-covariance alternative by dividing an approximate model covariance by the null standard deviation; that requires a separately specified alternative distribution. The b=210 comparisons have fewer blocks (477) and consequently less precision, but numerical power claims are not established here.

The finite cutoff z=613 is not the infinite Hardy–Littlewood singular-series model. The conditioned finite random sieve is an adapted BFT-inspired baseline. The result should not be described as confirmation of full Hardy–Littlewood predictions.

## 8. Corrected implementation status

On 2026-11-26 the C++ source was revised after the independent audit. The revised implementation:
- asserts the interval alignment, active-offset count, prime count/endpoints, block totals, pair-difference bounds, and thinning-probability bounds;
- computes the analytic expected raw residual cross-product average directly;
- compares the observed and simulated raw cross-product averages against that exact analytic expectation;
- reports the simulated-mean diagnostic in Monte Carlo standard-error units;
- uses nine marginal Monte Carlo p-values with Bonferroni adjustment and reports no joint maximum-statistic p-value.

The corrected rerun has now been completed locally and archived below. The earlier global p-value remains withdrawn.


## 9. Corrected rerun (2026-11-26)

A local C++17 build of the corrected implementation (same algorithm, parameters and assertions as the committed source) was compiled and run: 5,000 replicates for each b. The run completed successfully.

Validation:
- Prime count: 8,407; first prime 100,183; last prime 200,329.
- Block totals for b=10,30,210 each equal 8,407.
- Alignment, active-offset, pair-difference and thinning-probability checks passed.
- \(\Theta_{613}=0.0869350007731856\), and \(\Theta_{613}\log(100171)=1.0010247161>1\).
- The simulated means were all within 0.83 Monte Carlo standard errors of their exact analytic expectations. This supports the covariance calculation and implementation for the tested finite model.

### Interpretation

The corrected rerun finds no statistically significant departure from the specified z=613 finite conditioned random-sieve model for any of the nine statistics. Crucially, the simulated means agree closely with the analytic expectations, so the covariance calculation is now being checked rather than canceled out of the comparison.

This remains a compatibility result for one interval, three block lengths, three lags and this particular finite model. It is not proof of the model, independence, or the full Hardy–Littlewood conjecture. The b=210 estimates are visibly noisier because there are only 477 blocks. No formal power analysis was performed.

The original global p-value 0.9652 remains withdrawn. The corrected numerical output is in results/experiment_23B_heldout_covariance.json.
